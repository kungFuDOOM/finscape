# FinScape

Live globe of whales, sharks, and dolphins: satellite-tagged whales, sharks, and dolphins,
whale calls heard by hydrophone buoys and gliders, and research-grade sightings.

Data sources:

- OCEARCH satellite tags (via Mapotic)
- Southern right and sei whale tags from Siguiendo Ballenas, Falklands Conservation and the
  University of Auckland (public Wildlife Computers maps)
- Guy Harvey Research Institute mako shark tags (ghritracking.org)
- SharkSmart WA tagged-shark receiver detections and sightings
- WHOI Robots4Whales hydrophone detections (dcs.whoi.edu)
- Acartia live sightings (Pacific Northwest)
- iNaturalist research-grade observations
- Esri World Imagery tiles

```bash
npm install
npm run dev
```

The map opens at [http://localhost:8080](http://localhost:8080).
