# FinScape

Live globe of whales, sharks, and dolphins: satellite-tagged whales, sharks, and dolphins,
whale calls heard by hydrophone buoys and gliders, and research-grade sightings.

Data sources: OCEARCH tags (via Mapotic), southern right and sei whale tags from Siguiendo
Ballenas and Falklands Conservation (public Wildlife Computers maps), WHOI Robots4Whales
detections (dcs.whoi.edu),
iNaturalist observations, and Esri World Imagery tiles.

```bash
npm install
npm run dev
```

The map opens at [http://localhost:8080](http://localhost:8080).
